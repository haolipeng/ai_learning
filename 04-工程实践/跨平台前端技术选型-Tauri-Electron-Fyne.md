# 跨平台前端技术选型（与 coso 谈话摘录）

来源：与 coso 大佬的谈话。AI 时代角色与能力培养相关内容见 `01-认知与方法/整理和coso等大佬的谈话.md`。

## 1）Rust + React + Tauri

**优势：**打包体积小，内存占用低，安全性高。

**劣势：**Rust 学习门槛高，依赖系统 WebView（Windows 上是 WebView2，Linux 上是 WebKitGTK），相比 Electron 生态还不够成熟。

## 2）Electron（Node.js + Web 前端）

**优势：**生态最成熟，社区资源丰富，VSCode、Slack、Discord 等大型应用都在用。开发体验好，调试方便，纯前端团队可以快速上手。

**劣势：**打包体积大（最小也要 100MB+），内存占用高。启动速度相对较慢。

## 3）Go + Fyne

**优势：**纯 Go 开发。无需运行时依赖。打包体积小，启动快。Go 语言本身学习曲线平缓。大名鼎鼎的 Tailscale 就是用 Fyne 进行开发的。

**劣势：**UI 组件库相对简陋，视觉效果难以做得很精美。生态较小，复杂 UI 实现困难。

注意：不适合需要现代化、高颜值界面的应用。
